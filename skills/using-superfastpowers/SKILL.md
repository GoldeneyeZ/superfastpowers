# Using Superfastpowers

Use skills only when explicitly named or clearly relevant. Do not pause ordinary work for consent, load speculative skills, or invoke a skill on a remote possibility.

## Selection

1. Explicit named skill → load it.
2. Clear task match → load smallest relevant skill set.
3. Weak/uncertain match → proceed without skill.

User instructions override skill defaults. Never let a skill expand requested scope or force ceremony the user declined.

## Execution

- Read selected skill before acting.
- Apply only sections relevant to task.
- Prefer direct work over plans, subagents, or review stages for small changes.
- Use checklists internally; do not create tracking artifacts unless helpful.
- Combine compatible checks into one final verification batch.

## Platform Adaptation

Adapt generic tool labels to active platform. See `references/copilot-tools.md` and `references/codex-tools.md`; Gemini mappings live in `GEMINI.md`.

## Speed Rule

Default workflow: inspect → change → focused test → one review → finish.

Escalate only for demonstrated complexity, high risk, explicit request, or failing evidence.
